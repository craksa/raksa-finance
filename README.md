# 💰 Raksa Finance Tracker

Personal income & expenses tracker built with React.

## Features
- Monthly & Yearly reports
- Income and expense tracking
- Export / Import CSV
- Data saved in browser localStorage

## Deploy to GitHub Pages

1. Install dependencies:
   ```
   npm install
   ```

2. Update `homepage` in `package.json`:
   ```
   "homepage": "https://YOUR_USERNAME.github.io/raksa-finance"
   ```

3. Deploy:
   ```
   npm run deploy
   ```

## Run locally
```
npm start
```
